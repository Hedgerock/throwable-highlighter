# Changelog

All notable changes to the VS Code extension are documented here.

## [Unreleased]

## [0.2.0]

### Added

- Recognizes more Java `Throwable` subclasses through Java Type Hierarchy when the superclass cannot be read from the
  class declaration, including classes with an annotated superclass.

## [0.1.0]

### Added

- First public release of Throwable Highlighter for VS Code on Windows.

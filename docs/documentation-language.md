# Язык документации

## Основное правило

Публичная документация проекта ведётся на английском языке.
Внутренняя документация и материалы по сопровождению проекта ведутся на русском языке.

## Публичная документация

На английском языке оформляются:

- README.md;
- CHANGELOG.md;
- описание и change notes в plugin.xml;
- страница JetBrains Marketplace;
- GitHub Issues, pull requests и release notes.

## Внутренняя документация

На русском языке оформляются материалы в каталоге docs:

- описание архитектуры;
- правила сопровождения;
- roadmap;
- решения по развитию проекта;
- инструкции по выпуску и тестированию.

## Технические термины

Имена классов, файлов, цветовых ключей, Gradle-задач, PSI-элементов и элементов интерфейса IDE сохраняются на
английском языке.

Технический термин может использоваться на английском языке, если его перевод делает текст менее точным или затрудняет
поиск информации.

## Стиль

Документация описывает текущее состояние проекта, принятые решения и ожидаемое поведение.

Текст формулируется кратко, прямо и без рекламных оценок.

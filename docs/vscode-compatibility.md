# Совместимость расширения VS Code

Матрица фиксирует результаты проверки установленного VSIX `0.0.0`.
В манифесте расширения указана нижняя граница VS Code `1.101.0`.
Java-поддержка проверяется с Language Support for Java by Red Hat в режиме `Standard`.

| ОС          | VS Code   | `redhat.java` | Java проекта | Рабочая область | Результат                                                                                                                            |
|-------------|-----------|---------------|--------------|-----------------|--------------------------------------------------------------------------------------------------------------------------------------|
| Windows x64 | `1.85.0`  | `1.58.0`      | —            | Maven           | Активация `redhat.java` завершается ошибкой `tracingChannel is not a function`.                                                      |
| Windows x64 | `1.101.0` | Отсутствует   | —            | Maven           | Панель цветов и локальная диагностика доступны. Диагностика фиксирует `extension-unavailable`.                                       |
| Windows x64 | `1.101.0` | `1.58.0`      | `JavaSE-21`  | Maven           | После импорта подсветка применяется в открытом файле, включая вызов конструктора `SQLException`. Сценарий подтверждён в 10 прогонах. |
| Windows x64 | `1.101.0` | `1.58.0`      | `JavaSE-21`  | Gradle          | После импорта подсвечиваются типы из внешней зависимости и соседнего модуля. Сценарий подтверждён в 10 прогонах.                     |

Включение `redhat.java` в VS Code `1.101.0` восстанавливает подсветку в открытом Java-редакторе.
Диагностика фиксирует переход от `extension-unavailable` к `ready`.

Проверка VS Code `1.85.0` выполнена на ранней сборке, манифест которой допускал установку на эту версию.

## Проверка VSIX 0.1.0

Установленный VSIX `0.1.0` проверен на Windows x64 с VS Code `1.101.0`
и `redhat.java` `1.58.0` в режиме `Standard`. Подтверждены подсветка
в рабочих областях Maven и Gradle и применение выбранных цветов.

Результаты контрольного прогона и первого импорта сохранены
в [исследовании производительности](research/vscode-performance.md#контрольный-прогон-vsix-010).

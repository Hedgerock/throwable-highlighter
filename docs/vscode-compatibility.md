## Проверка VSIX 0.1.0

Установленный VSIX `0.1.0` проверен на Windows x64 с VS Code `1.101.0`
и `redhat.java` `1.58.0` в режиме `Standard`. Подтверждены подсветка
в рабочих областях Maven и Gradle и применение выбранных цветов.

Результаты контрольного прогона и первого импорта сохранены
в [исследовании производительности](research/vscode-performance.md#контрольный-прогон-vsix-010).

## Проверка Type Hierarchy

### Extension Host

На коммите `d583fe3` выполнен полный набор интеграционных тестов на Windows x64 с VS Code `1.101.0`
и `redhat.java` `1.58.0` в режиме `Standard`. Прошли 19 тестов.

Подтверждены резервный обход для класса с аннотированным родителем, определение наследников из JDK и библиотечного JAR,
различение класса проекта `Throwable` и `java.lang.Throwable`, а также параллельные обходы с общим ограничителем запросов.

### Установленный VSIX

На Windows x64 с VS Code `1.101.0` и `redhat.java` `1.58.0` в режиме `Standard` вручную проверен
тестовый VSIX `0.1.0` из коммита `2df1c3d` с `java.trace.server: off`.
SHA256 пакета — `EB8327F9313CF7586985E66E2C2BEA37716FAF5A245F8E3A970F1E82338A675A`.

После готовности Java в уже открытом редакторе подсветились импорт и ссылка на `AnnotatedFailure`.
В файле объявления подсветилось имя класса. Одноимённый метод и его вызов сохранили стандартную Java-подсветку,
как и `AnnotatedOrdinary` с локальным родительским классом `Throwable`.

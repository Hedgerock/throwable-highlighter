# ADR-0004: Платформенное развитие Throwable Highlighter

## Статус

Принято.

---

## Контекст

Throwable Highlighter реализован как плагин IntelliJ Platform.

Текущая реализация использует PSI, модель подсветки и настройки цветов IntelliJ Platform. Эти механизмы не используются
напрямую в VS Code, NetBeans и Eclipse IDE.

Поддержка новой платформы не должна изменять поведение, сборку и выпуск существующего IntelliJ-плагина.

Повторное использование платформенного кода до появления второй реализации не подтверждено.

---

## Решение

IntelliJ Platform остаётся единственной поддерживаемой платформой проекта.

VS Code становится первой платформой для исследования возможности расширения проекта.

До реализации адаптера VS Code проект фиксирует независимую от IDE спецификацию подсветки. Спецификация определяет:

- контексты `CLASS`, `IMPORT` и `CATCH`;
- правило определения `Throwable` и его наследников;
- правила наследования цветов;
- сценарии multi-catch;
- случаи, которые не должны подсвечиваться;
- общие Java fixtures и ожидаемые результаты.

Общий исполняемый модуль не создаётся.

Каждая поддерживаемая платформа использует собственную реализацию адаптера, сборку, тесты, публикацию и настройки цветов.

Адаптер VS Code сначала реализуется как технический прототип. Поддержка VS Code как пользовательской платформы принимается
отдельным решением после проверки прототипа.

Поддержка NetBeans, Eclipse IDE и других платформ требует отдельного решения.

---

## Рассмотренные варианты

### Немедленная поддержка нескольких платформ

Вариант отклонён.

Одновременная реализация адаптеров увеличит объем изменений и не позволит проверить совместимость модели подсветки с каждой
платформой последовательно.

### Общий исполняемый модуль

Вариант отклонён.

IntelliJ Platform, VS Code и NetBeans используют разные API для анализа Java, подсветки и настроек цветов. Общий модуль
создаст абстракции до подтверждения их необходимости.

### Независимые адаптеры без общей спецификации

Вариант отклонён.

Независимая реализация повышает риск расхождения поведения, тестов и пользовательской документации между платформами.

---

## Последствия

Структура и выпуск существующего IntelliJ-плагина сохраняются без изменения.

Перед разработкой адаптера VS Code появятся спецификация подсветки и общие fixtures.

Технический прототип VS Code проверит возможность определить типы `Throwable`, сохранить стандартную Java-подсветку и
предоставить настройку цветов.

Поддержка новой платформы потребует отдельной сборки, тестов, документации, публикации и сопровождения.

---

## Не входит в решение

- Реализация адаптера VS Code;
- Поддержка NetBeans, Eclipse IDE и других платформ;
- Создание Language Server Protocol сервера;
- Перемещение текущего IntelliJ-плагина в новую модульную структуру;
- Изменение существующих контекстов и цветовых ключей IntelliJ-плагина.

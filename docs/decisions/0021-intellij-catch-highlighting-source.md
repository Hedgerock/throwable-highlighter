# ADR-0021: Выбор источника подсветки Throwable catch в IntelliJ Platform

## Статус

Принято.

---

## Контекст

ADR-0003 устанавливает наследование `THROWABLE_CATCH` от `THROWABLE_CLASS`.

Пользователь может задать отдельные атрибуты `Throwable catch` в цветовой схеме.
Переключение между подсветкой плагина и стандартной Java-подсветкой отсутствует.

Выбор источника должен сохранять текущее поведение по умолчанию и ранее
настроенные атрибуты.

---

## Решение

Добавить в плагин IntelliJ Platform выбор источника подсветки контекста `CATCH`.

Доступны два источника:

- `Throwable catch` — применяются атрибуты ключа `THROWABLE_CATCH`;
- `Java highlighting` — сохраняется стандартная Java-подсветка IDE.

По умолчанию используется `Throwable catch`.

Для этого источника сохраняется существующее правило:
`THROWABLE_CATCH` наследует атрибуты `THROWABLE_CLASS`, пока пользователь
не задаст отдельные атрибуты в цветовой схеме.

При выборе `Java highlighting` плагин не создаёт дополнительную аннотацию
для ссылки на тип в параметре `catch`.

Такая ссылка сохраняет контекст `CATCH` и не обрабатывается повторно как `CLASS`.

Переключение источника не изменяет и не удаляет атрибуты цветовой схемы.
Возврат к `Throwable catch` восстанавливает применение настроенного стиля.

Выбор источника хранится на уровне IDE, применяется ко всем проектам
и сохраняется между запусками.

Настройка располагается в разделе:

`Settings | Tools | Throwable Highlighter`

Атрибуты `Throwable catch` продолжают настраиваться в разделе:

`Settings | Editor | Color Scheme | Throwable Highlighter`

Предпросмотр на странице цветовой схемы показывает атрибуты ключа
`THROWABLE_CATCH` независимо от выбранного источника.

Изменение источника применяется после подтверждения настроек.
Подсветка открытых редакторов обновляется без изменения исходного кода
и перезапуска IDE.

Выбор влияет только на типы в параметрах `catch`, включая multi-catch.
Ссылки внутри тела `catch` сохраняют существующие правила выбора контекста.

Решение расширяет ADR-0003 возможностью выбора стандартной Java-подсветки.
Правило наследования `THROWABLE_CATCH` и остальные положения ADR-0003
сохраняют силу.

---

## Рассмотренные варианты

### Изменять родительский ключ THROWABLE_CATCH

Вариант отклонён.

Источник подсветки и наследование атрибутов имеют разные назначения.
Переключение поведения не должно изменять существующую цепочку
наследования цветовых ключей.

### Хранить источник отдельно для каждого проекта

Вариант отклонён.

Выбор определяет личное оформление редактора.
Для первого среза используется единая настройка IDE.

### Хранить источник в каждой цветовой схеме

Вариант отклонён.

Первый срез разделяет выбор поведения и хранение атрибутов.
Дополнительная зависимость источника от цветовой схемы не вводится.

---

## Последствия

Пользователь получает возможность вернуть стандартную Java-подсветку
типов в `catch`, сохранив настройки плагина для остальных контекстов.

Существующие настройки продолжают работать без миграции.

Необходимо добавить хранение источника, страницу настроек, применение
выбора в аннотаторе и обновление подсветки после изменения настройки.

Проверки покрывают источник по умолчанию, сохранение выбора,
обычный catch, multi-catch и переключение между источниками.

Отдельно проверяются отсутствие аннотации плагина в режиме
`Java highlighting`, сохранение настроенных атрибутов и поведение
ссылок внутри тела catch.

Пользовательская и техническая документация описывают различие
между выбором источника и настройкой атрибутов цветовой схемы.

---

## Не входит в решение

- Выбор источника для других контекстов;
- Настройка источника на уровне проекта или отдельной цветовой схемы;
- Изменение правил определения типов Throwable;
- Изменение наследования цветовых ключей;
- Оптимизация разрешения типов и кэширования;
- Изменение настроек или критериев выпуска VS Code.

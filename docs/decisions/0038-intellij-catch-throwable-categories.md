# ADR-0038: Различать категории исключений в контексте CATCH

**Область действия** — IntelliJ Platform

## Статус

Принято.

---

## Контекст

ADR-0037 устанавливает отдельные цветовые ключи checked-типов, наследников `RuntimeException`
и наследников `Error` в контексте `CLASS`.

Типы в параметрах `catch` используют общий ключ `THROWABLE_CATCH`. В multi-catch пользователь может указать типы разных
категорий, которые получают одинаковое оформление.

Пользователю требуется различать категории типов в параметрах `catch`. При обновлении сохраняются настроенные атрибуты
`THROWABLE_CATCH` и выбранный источник подсветки контекста.

---

## Решение

Для типов в параметрах `catch` используются категории, определённые ADR-0037.
Категория определяется по иерархии разрешённого Java-класса через `ThrowableTypeClassifier`.

При выборе источника плагина для `CATCH` применяется цветовой ключ категории.

| Категория         | Настройка                           | Цветовой ключ                       |
|-------------------|-------------------------------------|-------------------------------------|
| Checked           | `Throwable catch checked`           | `THROWABLE_CATCH_CHECKED`           |
| Runtime exception | `Throwable catch runtime exception` | `THROWABLE_CATCH_RUNTIME_EXCEPTION` |
| Error             | `Throwable catch error`             | `THROWABLE_CATCH_ERROR`             |

В обычном `catch` категория определяется для указанного типа.
В multi-catch каждый тип классифицируется и подсвечивается отдельно.

Все три ключа по умолчанию наследуют атрибуты `THROWABLE_CATCH`. Ключ `THROWABLE_CATCH` наследует атрибуты `THROWABLE_CLASS`
согласно ADR-0003.

Настройка `Throwable catch` задаёт общие родительские атрибуты категорий контекста. При отсутствии собственных атрибутов
новых ключей применяется прежнее оформление `CATCH`.

Ключи категорий `CLASS` применяются к объявлениям классов и ссылкам этого контекста. Категории `CATCH` используют цепочку
наследования через `THROWABLE_CATCH`.

Источник подсветки выбирается для контекста `CATCH`. При выборе `Java highlighting` все типы параметров `catch` получают
стандартное оформление IDE. Ранее сохранённый источник применяется ко всем категориям контекста.

Обычные ссылки на классы внутри тела блока `catch` обрабатываются в контексте `CLASS`. Типы во вложенных параметрах `catch`,
списках `throws` и целевых Javadoc-тегах обрабатываются по правилам соответствующих контекстов.

Решение уточняет выбор цветового ключа `CATCH`, описанный в ADR-0028 и ADR-0037. Остальные положения этих решений сохраняют силу.

---

## Последствия

Страница цветовой схемы содержит три дополнительных элемента. Демонстрационный код показывает оформление категорий в
параметрах `catch`, включая multi-catch.

Классификация типов используется совместно с контекстом `CLASS`. Выбор применяемого цветового ключа учитывает контекст и категорию.

Автоматические проверки покрывают:

- базовые типы и транзитивных наследников каждой категории в обычном `catch`;
- выбор ключа для каждого типа в multi-catch;
- смешанные категории в одном multi-catch;
- наследование атрибутов `THROWABLE_CATCH`;
- применение ранее настроенных атрибутов `THROWABLE_CATCH` через новые ключи;
- независимость атрибутов категорий `CLASS` и `CATCH`;
- стандартное оформление всех категорий при источнике `Java highlighting` для `CATCH`;
- независимость источников `CLASS` и `CATCH`;
- разграничение обычных ссылок `CLASS` и вложенных контекстов `CATCH`, `THROWS` и `JAVADOC`
  внутри тела блока `catch`;
- отсутствие подсветки для обычных классов и неразрешённых типов.

Настройка цветов, наследование атрибутов и переключение источника проверяются вручную в sandbox.

---

## Не входит в решение

- Применение категорий в `IMPORT`, `THROWS` и `JAVADOC`.
- Независимый выбор источника для каждой категории.
- Оптимизация разрешения PSI-ссылок и кэширования.
- Изменения в расширении VS Code.

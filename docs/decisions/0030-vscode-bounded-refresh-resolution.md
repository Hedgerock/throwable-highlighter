# ADR-0030: Ограничение незавершённых определений типов при подсветке VS Code

## Статус

Принято.

---

## Контекст

Общий ограничитель допускает до 32 одновременно выполняющихся команд Java-провайдеров. Контроллер подсветки запускает
определения для всех кандидатов каждого видимого редактора.

В нагрузочном прогоне с пределом кэша 512 записей пик очереди Java-провайдеров составил 271 команду. Максимальный размер
карты незавершённых определений среди снимков составил 250 записей.

В контролируемом сценарии с двумя редакторами по 1000 кандидатов одно обновление запустило 2000 одновременных вызовов
управляемого resolver.

---

## Решение

Контроллер подсветки ограничивает число начатых и незавершённых вызовов `JavaTypeDefinitionResolver.isThrowableType`. Один
предел действует для всех видимых редакторов и поколений обновления. Значение является внутренним параметром и выбирается по
результатам измерений.

Кандидаты актуального обновления передаются в resolver по мере освобождения мест. После завершения одного определения
контроллер может запустить следующее. Каждый кандидат актуального обновления обрабатывается до применения подсветки в
своём редакторе.

Запрос нового обновления сразу прекращает запуск кандидатов предыдущего поколения. Планировщик
определяет момент запуска актуального обновления. Начатые определения удерживают места до завершения
и подчиняются правилам актуальности resolver.

Подсветка применяется отдельно для каждого редактора после обработки его кандидатов и проверки актуальности поколения,
документа и версии. Освобождение контроллера прекращает запуск новых определений и применение результатов.

---

## Последствия

Число незавершённых вызовов resolver со стороны контроллера ограничено выбранным пределом. Если места заняты, актуальное
обновление ожидает завершения начатых вызовов.

Автоматические проверки покрывают общий предел для нескольких редакторов, смену поколения при занятых местах, завершение
обработки актуального набора и освобождение контроллера.

В контролируемых измерениях сравниваются число запусков resolver, пик незавершённых вызовов и время применения подсветки.
В Extension Host дополнительно сравниваются очередь Java-провайдеров, карта незавершённых определений и память процессов.

---

## Не входит в решение

- Отмена уже начатых команд Java-провайдеров.
- Ограничение вызовов диагностической команды Inspect Definition.
- Изменение пределов кэша и параллельных команд Java-провайдеров.
- Численные бюджеты памяти и пользовательская настройка предела.

# ADR-0028: Выбор источника подсветки для контекстов IntelliJ Platform

## Статус

Принято.

---

## Контекст

Плагин IntelliJ Platform различает контексты `CLASS`, `IMPORT`, `CATCH`, `THROWS` и `JAVADOC`.

ADR-0021 устанавливает выбор между атрибутами плагина и стандартной Java-подсветкой для `CATCH`.
Остальные контексты всегда используют атрибуты плагина.

Пользователь может настроить отдельные атрибуты каждого контекста, но не может независимо
сохранить стандартное оформление IDE для объявлений классов, импортов, списков `throws`
или поддерживаемых Javadoc-тегов.

Расширение выбора источника должно сохранять настроенные атрибуты, существующее наследование
цветовых ключей и ранее сохранённый выбор для `CATCH`.

---

## Решение

Добавить независимый выбор источника подсветки для контекстов
`CLASS`, `IMPORT`, `CATCH`, `THROWS` и `JAVADOC`.

Для каждого контекста доступны два источника:

- источник плагина — применяются атрибуты соответствующего цветового ключа;
- `Java highlighting` — сохраняется стандартное оформление IDE.

Источник плагина отображается названием соответствующего элемента цветовой схемы.

| Контекст | Источник плагина    | Цветовой ключ       |
|----------|--------------------|---------------------|
| `CLASS`  | `Throwable class`  | `THROWABLE_CLASS`   |
| `IMPORT` | `Throwable import` | `THROWABLE_IMPORT`  |
| `CATCH`  | `Throwable catch`  | `THROWABLE_CATCH`   |
| `THROWS` | `Throwable throws` | `THROWABLE_THROWS`  |
| `JAVADOC` | `Throwable Javadoc` | `THROWABLE_JAVADOC` |

По умолчанию каждый контекст использует источник плагина.

Выбор источника не изменяет правила определения типа и контекста.

При выборе `Java highlighting` плагин не создаёт дополнительную аннотацию
для элемента выбранного контекста. Элемент сохраняет свой контекст
и не обрабатывается повторно как `CLASS`.

Источник `CLASS` применяется к объявлениям классов и ссылкам,
которые не относятся к другим поддерживаемым контекстам.

Источники контекстов не наследуются друг от друга.
Выбор `Java highlighting` для `CLASS` не отключает подсветку остальных контекстов.

Наследование атрибутов цветовых ключей сохраняется.
`THROWABLE_IMPORT`, `THROWABLE_CATCH`, `THROWABLE_THROWS` и `THROWABLE_JAVADOC`
продолжают наследовать атрибуты `THROWABLE_CLASS`.

Например, при стандартной подсветке `CLASS` и источнике плагина для `CATCH`
объявления классов сохраняют оформление IDE, а типы в параметрах `catch`
используют атрибуты `THROWABLE_CATCH`, включая унаследованные от `THROWABLE_CLASS`.

Переключение источника не изменяет и не удаляет атрибуты цветовой схемы.
Возврат к источнику плагина восстанавливает применение настроенного стиля.

Выбор хранится на уровне IDE, применяется ко всем проектам
и сохраняется между запусками.

Ранее сохранённый выбор источника `CATCH` из версии 1.4.0 сохраняется после обновления.
Повторная настройка со стороны пользователя не требуется.

При отсутствии сохранённого значения для контекста используется источник плагина.
Отсутствие новых настроек не изменяет сохранённый выбор `CATCH`.

Настройки источников располагаются в разделе:

`Settings | Tools | Throwable Highlighter`

Атрибуты продолжают настраиваться в разделе:

`Settings | Editor | Color Scheme | Throwable Highlighter`

Предпросмотр на странице цветовой схемы показывает атрибуты ключей плагина
независимо от выбранных источников.

Изменения источников применяются после подтверждения настроек.
Отмена закрывает настройки без применения черновика.

После применения подсветка открытых редакторов обновляется
без изменения исходного кода и перезапуска IDE.

Решение расширяет ADR-0021 выбором источника для остальных контекстов.
Остальные положения ADR-0021 сохраняют силу.

---

## Рассмотренные варианты

### Общий источник для всех контекстов

Вариант отклонён.

Общая настройка не позволяет сохранить стандартное оформление классов
и одновременно использовать отдельную подсветку в `catch`, `throws` или Javadoc.

### Изменять родительские цветовые ключи

Вариант отклонён.

Источник определяет применение дополнительной аннотации.
Наследование определяет атрибуты цветовой схемы.

Изменение источника не должно перестраивать цепочку наследования
или изменять сохранённые атрибуты.

---

## Последствия

Пользователь получает независимое управление применением подсветки
в каждом поддерживаемом контексте.

Модель настроек, страница выбора источников и проверка применения подсветки
расширяются на все пять контекстов.

Сохранение существующих настроек `CATCH` становится отдельным требованием совместимости.

Автоматические проверки покрывают:

- источники по умолчанию для всех контекстов;
- сохранение и восстановление независимых значений;
- загрузку настроек `CATCH` версии 1.4.0 для обоих источников;
- значения по умолчанию при отсутствии новых настроек;
- отсутствие аннотации плагина при выборе `Java highlighting`;
- сохранение выбранного контекста без повторной обработки как `CLASS`;
- независимость источника `CLASS` от остальных контекстов;
- сохранение атрибутов и цепочек наследования цветовых ключей;
- применение, отмену и восстановление черновика настроек;
- сохранение существующих границ подсветки и поддерживаемых PSI-сценариев.

Переключение источников и обновление открытых редакторов проверяются вручную в sandbox.

Пользовательская и техническая документация описывают различие
между источником подсветки и наследованием атрибутов.

---

## Не входит в решение

- Добавление новых контекстов и цветовых ключей;
- Изменение правил определения типов Throwable;
- Изменение наследования атрибутов;
- Настройка источников на уровне проекта или отдельной цветовой схемы;
- Оптимизация разрешения типов и кэширования;
- Изменение настроек или требований выпуска VS Code;
- Поддержка языков, отличных от Java.
